# Go2 运动控制

[English](MOTION.md)

九组 ABC policy 共用观测和电机接口。速度命令进入 235 维观测，policy 输出 12 个关节位置偏移，再由原实验的 DC 电机模型换算成 SDK2 力矩指令。

此前通过现场验收的[六方向原厂控制](../go2_sport/README.zh-CN.md)使用 SportClient，运行入口和验收记录单独保存。

## 控制接口

适配器保留仿真的关节顺序、默认姿态、`0.25` 动作缩放、`25/0.5` 控制增益，以及 `23.5 Nm / 30 rad/s` 力矩与转速参数。电机控制周期为 5 ms，每四步推理一次。SDK 指令关闭位置 PD，避免重复施加增益。

观测包含 48 个本体状态与命令值，以及 187 个地形值。外部感知模块须提供机身坐标系线速度，以及 `scan_xy()` 返回的网格对应的地面高度。网格只随偏航角旋转；地面高度与机身高度采用同一世界坐标系。高度差减去 `0.5 m`，再裁剪到 `[-1, 1]`。传感时间戳使用控制主机的单调时钟。[参数文件](control.json)记录来源版本。

## CPU 回放

准备好 [ABC 输入](README.zh-CN.md#准备输入)后，用提供的合成静止姿态数据检查控制链。以下命令不会建立 SDK2 通道。

```bash
python -m examples.embodiment.go2_abc.deploy \
  --task A --group rlinf \
  --frames examples/embodiment/go2_abc/frames.example.jsonl \
  --output /tmp/go2-A-rlinf-commands.jsonl
```

输出包含四帧按 SDK 顺序排列的关节目标和力矩。任务可选 A/B/C，组别可选 baseline/ppo/rlinf，覆盖九份权重。离线回放实测数据时，按示例字段替换 JSONL 输入。

## 接入 SDK2

在控制电脑安装固定版本的 [Unitree SDK2 Python](https://github.com/unitreerobotics/unitree_sdk2_python/tree/814556d15970dd2ecf1c9984e845ca02ab07e206)。`Go2SDK2(interface)` 订阅通过校验的关节与 IMU 状态，默认只读。

请在新进程内先连接 Sport 或 ABC，让适配器确认 SDK2 实际绑定的网卡。同一进程一次只能连接一个适配器。切换 DDS 网卡须重启进程。从其他线程关闭适配器后，须等原控制循环退出，才能重新连接该适配器。ABC 发送每条力矩指令前，会检查本轮控制是否超时，以及计算该指令所用的关节状态和感知数据是否过期。

在只读模式下，向 `run_control_loop()` 提供感知和速度指令回调，原厂控制器保持接管。循环最多等待一秒，收到新鲜且通过校验的关节状态后，才开始计算推理时长。

启用策略输出时，须为 `Go2SDK2(interface, enable_motion=True, acquire_control=...)` 提供独立控制器。ABC 先等待新鲜且通过校验的关节状态，一秒内未收到就终止连接。独立控制器独占该机的电机发布通道，通过 `SupervisedControl` 授予策略临时控制权，并能在客户端失联时自行接管。授权失败时须撤回已执行的授权操作。本仓库尚未提供该真机服务。

运行时间到后，策略继续控制，目标速度归零。独立控制器在交接前后都须提供足底接触、机身稳定性和电机控制权的实测反馈。四脚承重、机身直立且静止连续保持 0.5 秒后，程序才请求接管。接管方取得控制权且机器人再次连续站稳 0.5 秒，程序才正常退出。退出后由接管方继续支撑机身。

停步和接管确认各有 3 秒期限。反馈时间戳使用控制主机的单调时钟，两帧间隔超过 50 ms 就重新计时。超时会报错，并在清理时请求独立控制器接管。

控制循环超时时，程序立即请求交还控制权。清理只关闭本地订阅，不再发送电机指令。断网和进程终止时，由独立控制器的看门狗负责接管。

平地 MuJoCo 对照实验使用 A 任务基线，分别在前进 0.6、1.2 和 3.0 秒时将速度指令归零。三次均在请求后 0.61 秒内满足连续站稳 0.5 秒的条件，模拟接管后最后一秒均保持四脚承重。该实验使用仿真传感数据和电机模型。

## Limitations

CPU 测试覆盖观测和力矩计算、交接顺序、过期反馈与模拟故障。上述时间窗口用于软件验收；足底接触和站姿判定的标定、真机接管、断联和恢复仍需在目标机器上验证。
