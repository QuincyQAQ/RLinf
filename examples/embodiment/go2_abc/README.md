# Go2 locomotion

[简体中文](README.zh-CN.md)

Train a Go2 policy to walk in any direction, traverse rough terrain, or climb stairs with RLinf PPO. See [installation, task configs, and checkpoint inputs](../../../docs/source-en/rst_source/examples/embodied/go2_abc.rst).

For a trained policy, [replay recorded observations on CPU](MOTION.md). To check body velocity commands on a Go2 EDU, use the [six-direction Sport example](../go2_sport/README.md).
